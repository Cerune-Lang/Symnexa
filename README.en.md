# Symnexa

[日本語](README.md) | English

Symnexa is an experimental linker project for object files generated by [Cerune](https://github.com/Cerune-Lang/Cerune) and [Sashimi](https://github.com/Cerune-Lang/Sashimi).

Its first practical use is linking the x86-64 ELF64 kernel for [LiseOS](https://github.com/Cerune-Lang/LiseOS). **A Rust ELF64 linker is under implementation.** LiseOS still uses `ld.lld` for normal builds, while Symnexa is validated independently in CI.

## Purpose

```text
Cerune → Sashimi → ELF64 Object
                         ↓
                    Symnexa
                         ↓
                    LiseOS ELF64
                         ↓
                       Limine
```

## Build

Rust/Cargo is required.

```sh
cargo test
cargo run -- link --liseos -o liseos.elf kernel.o
```

`kernel.o` is an ELF64 object generated by Cerune/Sashimi. The current linker supports x86-64 static ELF64 output using the LiseOS layout.
