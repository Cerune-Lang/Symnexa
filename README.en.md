# Symnexa

[日本語](README.md) | English

Symnexa is an experimental linker project for object files generated by [Cerune](https://github.com/Cerune-Lang/Cerune) and [Sashimi](https://github.com/Cerune-Lang/Sashimi).

Its first practical use is linking the x86-64 ELF64 kernel for [LiseOS](https://github.com/Cerune-Lang/LiseOS). **Only documentation exists so far; the linker is not implemented.** LiseOS currently uses `ld.lld`.

## Purpose

```text
Cerune → Sashimi → ELF64 Object
                         ↓
                    Symnexa (planned)
                         ↓
                    LiseOS ELF64
                         ↓
                       Limine
```
